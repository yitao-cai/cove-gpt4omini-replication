# CoVe on GPT-4o-mini — Partial Replication (COMP8240)

This repository documents a **partial, substitution-based replication** of *Chain-of-Verification Reduces Hallucination in Large Language Models* (Dhuliawala et al., ACL 2024). It uses GPT-4o-mini and a modified **closed-book** community CoVe pipeline. This is **not** the original authors' code, model, question set, or official MultiSpanQA scorer.

## Headline results

| Evaluator | Baseline semantic-span micro-F1 | CoVe semantic-span micro-F1 |
|---|---:|---:|
| Single human reviewer | 57.14% | 56.23% |
| Same-model GPT-4o-mini judge | 59.40% | 59.78% |

These are **non-standard semantic-span scores**, not official MultiSpanQA Exact/Partial Match scores. The reconstructed subset has 60 questions (170 reference spans), with 120 reviewed generator answers and 120 successful judge evaluations. The raw judge log also has four unsuccessful retry records that are excluded from scoring.

For the six Boston/Chicago occupation-list prompts, baseline precision was 25/60 (41.7%) and CoVe precision was 14/24 (58.3%); however, the number of correct returned names declined from 25 to 14.

## Data origin and selection

Original MultiSpanQA dataset: Li et al. (NAACL 2022), <https://aclanthology.org/2022.naacl-main.90/>. Official source: <https://github.com/haonan-li/MultiSpanQA>. Dataset homepage: <https://multi-span.github.io/> (lists CC BY-SA 4.0).

`src/prepare_multispanqa.py` extracts the gold spans from BIO-labeled context tokens, de-duplicates identical gold spans ignoring case, filters for at least two spans with no span longer than three tokens, shuffles with seed 42, and saves the first 60 items. The source context was used only to build reference answers and was **not** supplied to GPT-4o-mini. Original CoVe paper's exact 418 question IDs were not recovered.

**Action required:** recover `data/multispanqa_pilot_60.manifest.json` from the local computer or recompute the SHA-256 of the exact source JSON; then update `data/provenance_template.json` and `DATA_PROVENANCE.md`. Do not claim to know the input filename or hash until verified.

## Reproduce a run

Use a Python virtual environment and record `python --version` and `python -m pip freeze > requirements-locked.txt` from the **actual tested environment**. A lockfile is not supplied in this starter archive because the exact tested dependency versions have not been independently recovered. Install `langchain`, `langchain-classic`, `langchain-openai`, `openai`, `python-dotenv`, and any libraries imported by your final local core scripts.

From the repository root, after copying the tested core files:

```powershell
# NEVER commit .env or an API key
# Set OPENAI_API_KEY in your private environment
cd src
python .\run_multispanqa_repro.py --dataset ..\data\multispanqa_pilot_60.jsonl --output ..\results\replication_new.jsonl --limit 5 --dry-run
```

**The existing published results are archived outputs from the original run, not regenerated by this starter package.** Do not overwrite the archived files when trying a new run.

## Ethics and disclosure

Public outputs may contain incorrect assertions about identifiable public figures. Human-vs-judge adjudications are post hoc and do not establish inter-rater reliability. No API keys or private `.env` files should be committed.
